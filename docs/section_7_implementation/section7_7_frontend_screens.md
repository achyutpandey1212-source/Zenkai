Implementation 7 — Frontend Screens

Purpose

This document defines every screen required for the Hackathon MVP.

The goal is NOT to build another productivity dashboard.

The goal is to make users feel:

"I don't have to carry everything in my head anymore."

The UI should feel:

Alive

Personal

Calm

Intelligent

Minimal

Not:

Corporate

Spreadsheet-like

Overwhelming

Design Philosophy

Most productivity apps begin with:

Graphs

Statistics

Charts

Task Lists

We will not.

We begin with:

Relationship

The AI Companion is the product.

Everything else supports it.

Design Principle

Every screen must answer:

What should I focus on?

Why does it matter?

What should I do next?

If a screen does not help answer those questions:

Remove it.

Minimal UI.

Maximum clarity.

Maximum trust.

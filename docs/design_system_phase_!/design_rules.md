# Zenkai Design System v1

## Purpose

This document defines the visual identity, UI philosophy, layout rules, typography, colors, spacing, and asset usage for Zenkai.

This document overrides default design decisions.

The goal is not to build another productivity app.

The goal is to build a luxury AI growth companion.

Users should feel:

* Calm
* Focused
* Guided
* Premium
* Understood

Never:

* Chaotic
* Gamified
* Corporate
* Startup-like
* Dashboard-heavy

---

# Design Philosophy

## Core Feeling

Zenkai is not a task manager.

Zenkai is not a chatbot.

Zenkai is not a project management tool.

Zenkai is a personal growth companion.

Visual Inspiration:

* Luxury jewelry stores
* Luxury watch brands
* High-end architecture
* Premium hotel lobbies
* Meditation spaces
* Ancient Hindu temples

The UI should feel:

"Expensive silence."

Large empty spaces are encouraged.

Do not fill screens unnecessarily.

Whitespace is a feature.

---

# Typography

## Heading Font

Cormorant Garamond

Usage:

* Main greetings
* Section titles
* Hero text

Examples:

Good Morning, Achyut

Today's Focus

Identity

Reflection

---

## Body Font

Inter

Usage:

* Paragraphs
* Chat messages
* Tasks
* Settings
* Navigation

Must be used everywhere outside headings.

---

## Signature Font

Allura

Usage:

Only for user name.

Example:

Good Morning,

Achyut

Never use for paragraphs.

Never use for buttons.

Never use for navigation.

---

# Layout Philosophy

## Maximum Width

Content should not stretch edge-to-edge.

Use centered content containers.

---

## Whitespace

Prioritize breathing room.

Every screen should feel:

60% content

40% empty space

Empty space is intentional.

---

# Navigation

Location:

Left sidebar.

Fixed.

Collapsed width:
80px

Expanded width:
240px

Navigation Icons:

* Home
* Chat
* Tasks
* Identity
* Reflection
* Settings

Icons must be minimal.

No colorful icons.

# Asset Usage

## Temple Backgrounds

Location:

Home Screen only.

Use:

Temple_01_Focus
Temple_02_Discipline
Temple_03_Growth
Temple_04_Wisdom
Temple_05_Mastery

Background Rules:

Temple on right side.

Empty space on left.

No overlays.

No blur effects.

Allow artwork to breathe.

---

## Companion Orb

The orb is the face of Zenkai.

Treat it as a character.

Files:

companion_orb.png

Location:

Home Screen

Chat Screen

Loading States

Do not use robot illustrations.

Do not use avatars.

Only use the orb.

Give subtle floating or subtle bg glow to orb while producing answer to show its talking.

Make the orb spin/swirl on its own axis and position periodically, not too instant, like every 60 sec.

---

# Home Screen

This is the most important screen.

The first screen should feel almost empty.

Layout:

Background Temple Asset

Centered Companion Orb

Greeting Text

Single Input Bar

Nothing else.

No dashboard.

No graphs.

No task tables.

No widgets.

No analytics.

No productivity clutter.

---

## Home Screen Structure

Top:

Greeting

Example:

Good Morning,

Achyut

Below Greeting:

Short AI message

Example:

I have already planned the day for you.

You have 3 priorities today.

Center:

Companion Orb

Bottom:

Large Ask Zenkai Input

Example:

Ask Zenkai anything...

---

# Chat Screen

Layout:

Minimal conversation interface.

No ChatGPT clone.

Use larger spacing.

Messages should feel premium.

Companion Orb remains visible.

---

# Tasks Screen

Do not look like Jira.

Do not look like Trello.

Tasks should feel curated.

Focus on:

Today's Priorities

Not giant task lists.

---

# Identity Screen

Purpose:

Show who the user is becoming.

Sections:

Long-Term Goal

Current Identity

Growth Traits

Patterns

Aspirations

This screen should feel reflective.

Not analytical.

---

# Reflection Screen

Purpose:

Show growth over time.

Not statistics.

Not charts.

Examples:

Lessons Learned

Recent Wins

Behavior Changes

AI Reflections

Growth Summary

---

# Animations

Use subtle animations only.

Examples:

Fade

Scale

Float

Glow

Never:

Bounce

Shake

Flash

Spin

Excessive motion

---

# Cards

Use soft rounded corners.

12px to 20px radius.

Subtle shadows.

Never harsh shadows.

Never glassmorphism.

Never neon.

---

# Buttons

Minimal.

Elegant.

Gold accent only for primary actions.

Secondary buttons should remain neutral.

---

# Things Zenkai Must Never Look Like

* Jira
* Trello
* Asana
* ClickUp
* Monday.com
* Notion Dashboard
* Corporate SaaS Products

---

# Final Design Test

Before approving any screen ask:

Does this feel like:

"A luxury growth companion"

or

"A productivity app"

If the answer is productivity app,

redesign the screen.

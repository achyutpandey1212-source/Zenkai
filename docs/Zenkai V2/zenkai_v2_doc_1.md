# Zen V2 – Landing Page Redesign
### "Stop Planning. Start Becoming."

---

# Vision

The current landing page is beautiful.

The new landing page should become unforgettable.

We are NOT redesigning the page because it looks bad.

We are redesigning it because it doesn't yet communicate the ambition behind Zen.

A visitor should not leave thinking:

> "This is an AI productivity app."

Instead they should leave thinking:

> "This feels like the operating system for my life."

Every scroll should reveal another layer of Zen.

The landing page should feel closer to Apple's product launches, Linear's website, Cursor's polish, and Vercel's storytelling than a traditional SaaS homepage.

The page should feel alive.

Not noisy.

Not overloaded.

Elegant.

Premium.

Purposeful.

---

# Core Principle

Never animate for decoration.

Every animation must explain something.

Every movement must have meaning.

If removing an animation makes the story weaker,
keep it.

If removing an animation changes nothing,
remove it.

---

# Performance Rules

This is NON-NEGOTIABLE.

The landing page should remain buttery smooth.

Requirements:

• Maintain 60 FPS whenever possible.
• Never chain expensive layout animations.
• Prefer opacity and transform animations.
• Avoid animating width/height continuously.
• Use GPU accelerated transforms.
• Lazy load heavy assets.
• Pause off-screen animations.
• Respect prefers-reduced-motion.

If any animation introduces jank,
replace it.

Premium > Fancy.

# Animation Rules

Every section fades into the next.

Avoid abrupt transitions.

Use Framer Motion.

Prefer:

opacity

translateY

scale (0.98 → 1)

blur reduction

Never use:

bounce

rubber band

flash

shake

spin

Animations should overlap slightly.

Nothing should feel like pages.

Everything should feel continuous.

---

# Scroll Behaviour

Scrolling should feel like reading a story.

Never force horizontal scrolling.

No scroll hijacking.

No pinned sections longer than necessary.

Parallax should remain subtle.

---

# Responsiveness

Desktop first.

Tablet second.

Mobile third.

Do NOT simply stack desktop layouts.

Redesign sections where necessary.

Animations should degrade gracefully.

---

# Accessibility

Respect reduced motion.

Proper semantic headings.

Keyboard navigation.

Readable contrast.

Focusable buttons.

Alt text.

---

# Technical Constraints

Do not introduce unnecessary dependencies.

Prefer Framer Motion.

Use Intersection Observer where appropriate.

Lazy load heavy illustrations.

Optimize all images.

Maintain Lighthouse performance.

Avoid hydration issues.
